# NetPractice

> Discover the basics of computer networking through a series of simulated exercises.

## 🧠 Project Summary

**NetPractice** is a practical project aimed at helping you understand core networking concepts, particularly how TCP/IP addressing works in small-scale networks. This project is part of the 42 Network curriculum.

## 🗂️ Project Structure

This project consists of **10 levels** of networking problems. Each level presents a non-functional network that you must fix using the training interface provided.

## 🚀 How to Use

1. Download the attached project files from the **intranet**.
2. Extract the files and open `index.html` in your browser.
3. Either:
   - Enter your **login** to start the training mode.
   - Or leave it empty to try the **correction mode**.
4. For each level:
   - Follow the instructions shown at the top of the interface.
   - Modify the network configuration accordingly.
   - Click **[Check again]** to test your changes.
   - Click **[Get my config]** to export your solution.
5. Save each exported file in your Git repository as `level_X.txt` (where `X` is the level number from 1 to 10).

## 📁 Repository Requirements

- Your repository must contain **10 configuration files**, one for each level.
- These files should be located in the **root directory** of your repository.
- Make sure your **login** is entered before exporting each file.
- Do **not** use any external tools. Only basic tools like `bc` (calculator) are allowed.

## 🛡️ Defense Guidelines

- You will be asked to solve **3 random levels** during the defense.
- Ensure you are well-prepared and can complete the exercises without external help.

## 🧰 Tools and Restrictions

- No external libraries, packages, or tools are allowed.
- Use only the official training interface and configuration export tool.

## 💡 Tips

- Familiarize yourself with subnetting and IP addressing.
- Review how routers and IP masks work together in a network.
- Pay attention to the **logs** at the bottom of the interface to debug your configurations.
